# Security Policy

## Scope

mbtop is a local terminal monitor. It does not provide a network service, accept remote commands, or require elevated privileges by default.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use the repository host's private vulnerability reporting or contact a project maintainer through a private channel first. Include the affected version, platform, reproduction steps, and impact, while removing secrets and private machine information.

If a report is accepted, maintainers will coordinate a fix, document the affected versions, and credit the reporter when desired. Until a fix is available, please avoid sharing exploit details publicly.

## Supported versions

Only the latest published release and the current default branch are expected to receive security fixes.

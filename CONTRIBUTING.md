# Contributing

Thanks for helping make mbtop useful in small terminal panes.

## Before opening a pull request

- Keep the default view compact and readable at roughly 40 columns.
- Prefer standard-library solutions when they keep the code clear.
- Add or update focused tests for formatting and sampling behavior.
- Run `cargo fmt --check`, `cargo test`, and `cargo clippy --all-targets --all-features -- -D warnings`.

Please describe the terminal size and operating system you used when reporting a rendering issue.

Pull requests should explain the user-visible change, keep the default view compact, and complete the checklist in the repository pull request template.
